# Skills

Claude skills that ship with this repo. Anyone who clones it and opens the
folder in Claude Code or Cowork gets them automatically — no account setup, no
copying files around. That is the point: publishing knowledge lives next to the
code it describes, and a new person inherits it with the clone.

| Skill | What it covers |
|---|---|
| `ps-blog-writer` | The blog voice — three archetypes, structure, pull quotes, the anti-patterns to strip |
| `ps-blog-publish` | Getting a post from a Notion draft to live: setup, the run, the two manual edits, branches and deploys |

Directory-scoped skills win over same-named account skills when you are working
in this repo, so these are the canonical copies. If you also have account-level
versions, they are the ones that go stale — edit here.

The human-readable version of the publishing process, for people who want to
read rather than invoke, is `docs/publishing.md`. It and `ps-blog-publish`
describe the same process and should be changed together.
